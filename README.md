# Cooking Assistant

A simple AI-powered micro-app that helps users generate a personal cooking to-do list based on their day.

## Key Features

- **Structured Meal Planning Flow:** Generates detailed Breakfast, Lunch, and Dinner plans.
- **Grocery List:** Provides a structured list of ingredients needed.
- **Substitutions:** Recommends alternative ingredients when needed.
- **Budget Feasibility Logic:** Evaluates cost/budget constraints.
